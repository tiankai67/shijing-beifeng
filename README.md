# 诗经 · 邶风 — 汤阴文化学习网站

一个以《诗经·邶风》十九篇为主题的古典文化学习网站，内容源于汤阴县「邶风故里」文化资料与公开史料拓展。

## 内容

- **邶风渊源**：邶风何来、邶国与邶城、武王封邶、汤阴三圣、千年爱情圣地、邶国遗址保护公园。
- **十九篇**：柏舟、绿衣、燕燕、日月、终风、击鼓、凯风、雄雉、匏有苦叶、谷风、式微、旄丘、简兮、泉水、北门、北风、静女、新台、二子乘舟。每篇含原文、译文、注释、赏析与适用场景。
- **五大主题**：爱情之美 · 亲情之厚 · 乡愁之深 · 品格之坚 · 自然之韵。
- **文旅推荐**：依文旅文案优先级的四句重点宣传诗句。
- **研学互动**：「邶风填句」小游戏。

## 技术

纯静态前端（HTML / CSS / JavaScript），无构建步骤、无后端依赖。

```
site/
├── index.html
├── css/style.css
└── js/
    ├── data.js   # 十九篇与文旅数据
    └── app.js    # 筛选、检索、卷轴详情、填句互动
```

## 本地预览

```bash
cd site
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/
```

## 说明

诗句译文与赏析依资料整理，仅供文化研习参考。文档中标注「不宜选用」的三篇（谷风、北门、新台）仍予收录，但详情页加「文旅建议·慎选」提示。
